# AI Workspace Landing Page

A modern, responsive AI workspace landing page built with **HTML5 and Tailwind CSS**.

## Features

- Responsive navbar
- Modern hero section
- Call-to-action buttons
- Background image with `bg-cover`
- Project status and activity cards
- Responsive design

## Technologies

- HTML5
- Tailwind CSS
- Flexbox
- Responsive Design

## How to Run

Open `index.html` in your browser or use **VS Code Live Server**.
